# 📊 Excel Sales Dashboard Project

## 📌 Project Overview

This project demonstrates the creation of an **interactive Excel dashboard** using a structured dataset. It covers the complete workflow from data cleaning to visualization and storytelling using advanced Excel features.

---

## 🎯 Objectives

* Clean and preprocess raw data
* Perform data analysis and summarization
* Apply advanced Excel formulas
* Build an interactive dashboard
* Present insights in a clear and visual format

---

## 🛠️ Tasks Implemented

### 🔹 1. Dataset Selection & Import

* Imported dataset into Excel
* Performed initial inspection and validation

### 🔹 2. Data Cleaning & Preparation

* Removed duplicate values
* Handled missing data
* Standardized formats (Date, Currency, Text)

### 🔹 3. Pivot Tables

* Created Pivot Tables for:

  * Sales analysis
  * Profit insights
  * Customer performance
* Used grouping and filters

### 🔹 4. Advanced Formulas

* Applied key formulas:

  * `VLOOKUP`
  * `INDEX-MATCH`
  * `IF` (nested conditions)
* Enabled dynamic calculations

### 🔹 5. Data Visualization

* Built charts:

  * Bar Chart
  * Line Chart
  * Pie Chart
* Used Conditional Formatting:

  * Data bars
  * Icons (↑ ↓ trends)
  * Highlight top values

### 🔹 6. Interactive Dashboard

* Implemented:

  * Slicers (for filtering)
  * Timeline (date filtering)
  * Dynamic data ranges
* Created a user-friendly layout

### 🔹 7. Documentation

* Organized sheets properly
* Used clear naming conventions
* Added instructions for navigation
